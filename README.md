# FlipCover

Galaxy Z Flip7 のカバー画面に、光の時計とアプリ・ウィジェットなどを表示する自作アプリです。

## 仕組み
端末を閉じると、カバー画面（displayId=1）だけが点灯します。FlipCover は、そのカバー画面に全画面の「ふつうの画面」を出します。

6.0.0 から、**FlipCover 自身は裏で動き続けません**。閉じたことを見張って画面を出す役は、Galaxy に最初から入っている「モードとルーチン」に任せます。

- **閉じたら自動で出す**：「モードとルーチン」に「折りたたみの状態が閉じた → FlipCover を開く」というルーチンを 1 つ作る（下の「インストールと更新」）。閉じている間に FlipCover が開かれると、設定画面ではなくカバー画面の表示になる
- 一度開いた FlipCover の画面は、ロック中でも出る画面なので、カバー画面が消えて点き直しても残る
- **使わないもの**：ユーザー補助（PayPay や銀行のアプリが決済を止める）、他のアプリの上に重ねて表示、常駐、起動時の自動開始
- **Google Play プロテクトについて**：5.1.x までの「重ねて表示＋常駐」の組み合わせは、Play プロテクトに「有害なアプリ」と判定されました。6.0.0 からはどちらも使わず、マニフェストからも消しています。それでも 6.0.0 は有害と判定されたので、6.0.1 で、6.0.0 で足したカバー画面のウィジェットと、全画面表示を「ひとつだけ・履歴に出さない」にする指定をやめ、判定されなかった 5.0.0 に近づけました

## 権限
| 権限 | 使い道 |
|---|---|
| 付近のデバイス | Bluetooth 機器の電池残量（使わなくてもよい） |

## できること
- **見た目**：「光の時計」と「ステッチ」（黒い布地に白い糸の縫い目。ホーム画面の FlipHome と同じ）から選べる（設定の「時計」）
  - ステッチでは、画面の縁をぐるりと縫い、時計はフェルトの丸い文字盤：12 時から今の分までを内側の輪に縫い進めた糸目で表し、時針はサテン刺繍、分針はステッチ、秒は縫い針が 1 秒ずつ進む。デジタル時計も縫った数字になる。アプリのボタンは巾着、ウィジェットのボタンはジーンズのポケット、アプリのアイコンはワッペンに、そのアプリのアイコンをなぞった刺繍（FlipHome の「アプリのアイコンをなぞる」と同じ。アイコンの色の糸か、生成りの糸で縫う）と、その下に小さくアプリ名。設定でジャンルのアイコン（FlipHome と同じ 31 種）にもできる、電池は糸で埋めた棒、ライトのスイッチはフェルトの帯に縫い付けボタンのつまみになる
- **時計**：画面全体が光の時計になる。中心から放射する淡い扇形の光（12 時から今の分まで）と、ふんわり光る針で時刻を表す
  - 時針＝オレンジ、分針＝白、秒＝黄色（残像つき）。光の強さを調整できる
  - 秒つきのデジタル時計も並べて表示できる（後ろのぼかしつき）。針と同じく、時＝オレンジ、分＝白、秒＝黄色
- **カバー画面のアプリ**：最大 16 個。ふだんはボタン 1 つにまとめ、タップで 4 列のグリッドに展開する（ボタンのデザインは 5 種類、グリッドの範囲はプレビューで調整）。アイコンのタップでカバー画面上に起動
- **ウィジェット**：ほかのアプリのホーム画面用ウィジェット（カレンダーの今日の予定、Suica の残高など）を最大 4 個置ける。2 列に並べ、横長のウィジェット（予定の一覧など）は 1 つで 1 段を使う（見分けられないときは「すべて 1 列に並べる」）。「ボタンにまとめる」をオフにすると常に表示し、オンにするとふだんはボタン 1 つにまとめてタップで展開する（初回だけ使用の許可を確認される）
  - 今日の予定を出すには：「ウィジェット」→「ウィジェットを追加」でカレンダーの予定の一覧のウィジェットを選び、「ボタンにまとめる」をオフにして、プレビューで位置と大きさを合わせる。カレンダーの読み取りの権限は FlipCover には要らない（予定を読むのはカレンダーアプリ自身）
- **電池残量**：本体と、接続中の Bluetooth 機器（イヤホンなど。Galaxy Fit やスマートリングのような残量を報告しない機器には直接問い合わせる）の残量を、横棒と % で右端に小さく常に表示（Bluetooth 機器は「付近のデバイス」の許可が必要）
- **ライト**：横長のスイッチを右へスワイプで点灯、左へスワイプで消灯（タップでは切り替わらないので、触れただけでは点かない）
- **配置**：プレビューでドラッグ・ピンチして位置と大きさを調整（中央や 3 分割の線に吸い付く。カメラの位置も表示）
- アプリを開いて戻ると、FlipCover の画面に戻る
- ダブルタップで閉じる（次に閉じたときに、また出る）

## 設定画面
左の列でカテゴリ（全般・時計・アプリ・ウィジェット・電池・ライト）を選ぶと、右下にその設定だけが出る。右上のプレビューは常に表示され、ドラッグ・ピンチで配置を調整できる。

## 4.0.0 でアプリの ID が変わりました
アプリの ID を `com.example.flipcover` から `io.github.yukichi006.flipcover` に変えました。古い FlipCover（`com.example.flipcover`）はアンインストールしてください（カバー画面の設定は引き継がれないので、設定し直してください）。

## インストールと更新
`main` に push すると GitHub Actions が APK をビルドし、[Releases](../../releases) に `flipcover-v<バージョン>.apk` を公開します。

1. [Obtainium](https://github.com/ImranR98/Obtainium) に、このリポジトリの URL を登録する
2. 「インストール」または「アップデート」を押す（Galaxy のオートブロッカーは、そのときだけオフにする）
3. 初回だけ：閉じたら自動で出るように、ルーチンを作る（FlipCover の「全般」にも同じ手順とボタンがある）
   1. 設定 →「モードとルーチン」→「ルーチン」→「＋」
   2. 条件（もし）：「折りたたみの状態」→「完全に閉じた状態」
   3. 実行内容（実行）：「アプリ」→「アプリを起動」→ FlipCover
   4. 保存
4. 5.1.x から更新したとき：設定 → アプリ → FlipCover の「他のアプリの上に重ねて表示」は、もう使わないのでオフのままでよい

APK は Secrets の固定の鍵で署名するので、上書きで更新できます（`FLIPCOVER_KEYSTORE_B64` と `FLIPCOVER_KEYSTORE_PASSWORD`）。

## バージョンの付け方
バージョンはリポジトリ直下の `VERSION` ファイル（`メジャー.マイナー.パッチ`）で決め、リリースのたびに更新の大きさに合わせて上げる。上げ忘れて同じバージョンを公開しようとすると、リリースは止まる。

- **メジャー**（例: 1.4.2 → 2.0.0）：大きな作り直し。画面の構成が大きく変わる、設定が引き継がれないなど
- **マイナー**（例: 1.4.2 → 1.5.0）：新しい機能の追加
- **パッチ**（例: 1.4.2 → 1.4.3）：不具合の修正や見た目の微調整

`versionCode`（上書き更新の判定に使う内部の番号）は、これまでどおり CI の実行番号で自動的に増える。

## ビルド
- **GitHub Actions**：push すると自動でビルド・公開
- **手元**：`./gradlew assembleDebug`（Android SDK が必要）

## 調整したいとき
- 閉じても出ないとき：FlipCover の「全般」の下の「閉じたら出す仕組みの記録」を見る。いつ・どの画面がどう点いているときに・どう判断したかが、新しい順に残っている（端末の中にだけ残る）
- カバー画面が見つからないとき：アプリ下部の「ディスプレイ情報」を見て、`CoverContent.findCoverDisplay()` の id を直す
- 光の時計の見た目：`LightDialView.kt`
- ステッチの見た目：`StitchViews.kt`
- 2.0.0 で、使っていなかった背景（ドット時計・機材風・宇宙）と時計のデザインを削除した。必要になったら git の履歴（1.1.x 以前）から戻せる
