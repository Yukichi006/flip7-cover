# FlipCover

Galaxy Z Flip7 のカバー画面用の、自作のホーム。見た目は「黒い布地に白い糸のステッチ」。
メイン画面用の [FlipHome](https://github.com/Yukichi006/flip7-home) の姉妹アプリで、7.0.0 から、作りも操作も FlipHome と同じにしました（FlipHome のコードを移して、カバー画面用に直したもの）。

## 仕組み
端末を閉じると、カバー画面（displayId=1）だけが点灯します。FlipCover は、そのカバー画面に全画面の「ふつうの画面」を出します。

- **FlipCover 自身は裏で動き続けません**。閉じたことを見張って画面を出す役は、Galaxy に最初から入っている「モードとルーチン」に任せます（「折りたたみの状態が閉じた → FlipCover を開く」というルーチンを 1 つ作る。下の「インストールと更新」）
- 閉じている間に FlipCover が開かれると、カバー画面の表示になる。ロック中でも出る画面なので、カバー画面が消えて点き直しても残る
- 端末を開くと、カバー画面の表示は自分で閉じる（メイン画面に残らない）。次に閉じたときに、また新しく出る
- **使わないもの**：ユーザー補助（PayPay や銀行のアプリが決済を止める）、他のアプリの上に重ねて表示、常駐、起動時の自動開始、インターネット、通知へのアクセス、カレンダーの読み取り
- **Google Play プロテクトについて**：5.1.x までの「重ねて表示＋常駐」の組み合わせは「有害なアプリ」と判定されました。6.0.0 で足したカバー画面のウィジェットなども判定されたので、いまは権限もマニフェストも、判定されなかった形（画面 2 つと、Bluetooth の電池残量の権限だけ）にしています
- ライブラリは使わず、Android の標準機能と Kotlin だけで作っています

## 権限
| 権限 | 使い道 |
|---|---|
| 付近のデバイス | Bluetooth 機器の電池残量（使わなくてもよい） |

## 操作（FlipHome と同じ）
- **マス目**：どのページも同じマス目（最初は 5 列。行の数は画面の高さで決まる）。時計・電池・ライト・アプリ・巾着・ウィジェットなど、どの部品もブロックとして好きなマスに置く
- **ページ**：左右へスワイプで移る。編集モードの「…」→「ページを足す」で足す
- **アプリ一覧**：上へスワイプ（最後のページでさらに左へスワイプしても出る）
- **編集モード**：どこかを長押しすると入る
  - 空いたマスをタップ → 下から出るパネルで「アプリ」か「部品」を選んで置く
  - ドラッグで移動、右上の × で外す、右下のつまみで大きさを変える
  - 部品をタップ → その部品の設定（アプリを変える、名前、アイコンの描き方、別のページへ移す、など）
  - 上の帯の「…」 → ページ・列の数・糸の太さ・なぞる刺繍の糸・アプリ名の出し方などの設定、「FlipCover を閉じる」
  - カメラの位置は赤く示す（そこに置いた部品は見えない）
- **メイン画面でも編集できる**：FlipCover をメイン画面で開く →「メイン画面で配置を編集する」。カバー画面と同じ縦横の比の枠で、同じように編集できる。ほかのアプリのウィジェットを置くとき（初回は Android の確認が出る）や、文字を打つときに向いている

## 部品
- **パッド**（1 マス）：ワッペンに載せたアプリ。アイコンは、そのアプリのアイコンをなぞった刺繍（アイコンの色の糸か、生成りの糸）。アプリごとに、ジャンルのアイコン（31 種）にも変えられる。裏地のアプリを決めておくと、端をめくって開ける
- **巾着**（1 マス）：フォルダ。タップすると口が開いて、中のアプリが出てくる
- **めくれるパネル**：アプリを並べた布。角をめくると次の布が出る
- **アプリのウィジェット**：ほかのアプリのホーム画面用ウィジェット（カレンダーの今日の予定、Suica の残高など）。空いたマス →「部品」→「アプリのウィジェット」。大きさは右下のつまみで変える
  - **今日の予定**は、カレンダーアプリの予定の一覧のウィジェットを置く（FlipCover にカレンダーの権限は要らない。予定を読むのはカレンダーアプリ自身）
- **アナログ時計**：フェルトの丸いワッペンに縫い付けた文字盤
- **時計と日付**／**時刻**（秒も出せる）／**日付**／**月のカレンダー**／**見出し**
- **電池**：本体と Bluetooth 機器の残量
- **ライト**：フェルトの帯のスイッチ。右へスワイプで点灯、左へスワイプで消灯（タップでは切り替わらないので、触れただけでは点かない）
- **次のアラーム**／**縫い付けメモ**／**フェーダー**（音量、アプリを開くバネ）
- **下段のポケット**：最初は隠してある（「…」→「下段のポケットを出す」）
- FlipHome にあって FlipCover にないもの：天気（インターネットを使うため）、再生中の曲と通知の印（通知へのアクセスを使うため）、今日の予定・ひと月の予定の刺繍（カレンダーの読み取りを使うため）、明るさのフェーダー、ロック画面の壁紙

## 6.x からの引き継ぎ
7.0.0 は大きな作り直しで、6.x までの配置（自由な位置と大きさ）は引き継ぎません。最初の配置は、アナログ時計・時刻・日付・電池・ライトです。
6.x で選んでいたアプリは巾着 1 つにまとめ、置いていたウィジェットは 2 ページ目に並べます。「光の時計」の見た目はなくなりました（必要なら git の履歴の 6.x から戻せます）。

## インストールと更新
`main` に push すると GitHub Actions が APK をビルドし、[Releases](../../releases) に `flipcover-v<バージョン>.apk` を公開します。

1. [Obtainium](https://github.com/ImranR98/Obtainium) に、このリポジトリの URL を登録する
2. 「インストール」または「アップデート」を押す（Galaxy のオートブロッカーは、そのときだけオフにする）
3. 初回だけ：閉じたら自動で出るように、ルーチンを作る（FlipCover をメイン画面で開くと、同じ手順とボタンがある）
   1. 設定 →「モードとルーチン」→「ルーチン」→「＋」
   2. 条件（もし）：「折りたたみの状態」→「完全に閉じた状態」
   3. 実行内容（実行）：「アプリ」→「アプリを起動」→ FlipCover
   4. 保存
4. 5.1.x から更新したとき：設定 → アプリ → FlipCover の「他のアプリの上に重ねて表示」は、もう使わないのでオフのままでよい

APK は Secrets の固定の鍵で署名するので、上書きで更新できます（`FLIPCOVER_KEYSTORE_B64` と `FLIPCOVER_KEYSTORE_PASSWORD`）。

## バージョンの付け方
バージョンはリポジトリ直下の `VERSION` ファイル（`メジャー.マイナー.パッチ`）で決め、リリースのたびに更新の大きさに合わせて上げる。上げ忘れて同じバージョンを公開しようとすると、リリースは止まる。

- **メジャー**（例: 1.4.2 → 2.0.0）：大きな作り直し。画面の構成が大きく変わる、設定が引き継がれないなど
- **マイナー**（例: 1.4.2 → 1.5.0）：新しい機能の追加
- **パッチ**（例: 1.4.2 → 1.4.3）：不具合の修正や見た目の微調整

`versionCode`（上書き更新の判定に使う内部の番号）は、これまでどおり CI の実行番号で自動的に増える。

## ビルド
- **GitHub Actions**：push すると自動でビルド・公開
- **手元**：`./gradlew assembleRelease`（Android SDK が必要）

## 調整したいとき
- 閉じても出ないとき：FlipCover をメイン画面で開き、いちばん下の「閉じても出ないときの記録」を見る。いつ・どの画面がどう点いているときに・どう判断したかが、新しい順に残っている（端末の中にだけ残る）
- 落ちた・固まったとき：次に開いたときに、そのときの記録が画面に出る（コピーできる。端末の中にだけ残る）
- カバー画面が見つからないとき：`CoverActivity.findCoverDisplay()` を直す
- 主なファイル：`CoverActivity.kt`（カバー画面の表示と編集）、`MainActivity.kt`（案内の画面と、閉じたら出す仕組み）、`HomeLayout.kt`（部品の種類と配置の保存）、`TorchSwitch.kt`（ライト）。ほかは FlipHome と同じ名前・同じ役割
